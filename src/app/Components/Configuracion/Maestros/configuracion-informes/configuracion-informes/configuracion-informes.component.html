Ayuda
  • Todos los campos marcados con * son obligatorios.
  • Para guardar la configuración debe presionar el botón "Guardar".
  • Para actualizar la configuración se debe dar clic sobre el botón editar de la tabla.
  • Para que se visualicen nuevos módulos en la lista desplegable, se debe matricular en el módulo operaciones módulos, se busca informe ahorros y se le adicionan los nuevos módulos.
  • Para habilitar el acceso del módulo a los perfiles, se debe dar acceso a Informe de Ahorros y en las operaciones, el acceso a los módulos de informes que se requiera.
  • Para habilitar informes específicos como los dinámicos o predeterminados, se debe gestionar en este módulo desde la operación permisos.
  • Los listados relacionados con oficina, deben tener el código de filtro 999
  • Si se define un filtro o campo que contenga la palabra oficina, de forma automática se configurará así:
    • Si el usuario está en administración, el listado estará habilitado y podrá elegir cualquir oficina o todas.
    • Si el usuario está en oficina diferente a administración, dejará el campo deshabilitado y seleccionado en la oficina donde se encuentre.
  • Recomendación para la estructuración de los SP:
    • Los parámetros de entrada del procedimiento todos deben declararse =NULL.
    • Si el procedimiento maneja acciones, se debe declarar el primer parámetro con la palabra reservada @Accion.
    • Si requiere que un campo numérico tome el formato de moneda en la visualización del informe, se debe poner al final del nombre del campo la palabra reservada _M, ejemplo Saldo_M.
