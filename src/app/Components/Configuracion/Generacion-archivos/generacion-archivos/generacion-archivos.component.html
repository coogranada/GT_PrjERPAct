Ayuda
  • Todos los campos marcados con * son obligatorios.
  • Para guardar la configuración debe presionar el botón "Guardar".
  • Para actualizar la configuración se debe dar clic sobre el botón editar de la tabla.
  • GPG Recipient es la persona o entidad a la que se le envía un mensaje cifrado usando GPG (GNU Privacy Guard). Este receptor tiene la clave privada necesaria para descifrar el mensaje.
  • Las tareas que se programen para las 00:00:00 o 12:00:00 a.m. No se ejecutan.
  • En caso no haber rutas específicas puede usar el comodín / para indicar que se utilizará el directorio raíz.
  • Desde el historial de ejecuciones, solo se habilita la opción de reintentar ejecución manual, si la tarea presentó error y si está dentro de los últimos 5 días.
  • Si se crea una nueva configuración o se modifica alguna hora de ejecución, se debe confirmar la programación de tareas.
  • Si requiere crear un sitio que tenga especificado algún puerto, el puerto se indicará después de : dos puntos y seguido, ejemplo sftp.sitio.net:2244
